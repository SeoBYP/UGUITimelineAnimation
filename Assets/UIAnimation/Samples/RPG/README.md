# RPG

모바일 RPG의 로비와 거기서 열리는 화면들을 UI Animation으로 만든 샘플입니다. 판타지 스타일 하나로 만들었습니다.
화면의 움직임은 모두 각 Prefab의 **UIAnimation 상태**이고, 스크립트는 화면을 열고 닫고 데이터를 채우기만 합니다.
상태는 UI Animation 창에서 열어 고칠 수 있습니다.

| 화면 | 보여 주는 것 |
|---|---|
| 로비 | 패널·재화·영웅·메뉴가 순서대로 들어오는 등장, 영웅 숨쉬기와 퀘스트 배지 반복(`RpgRepeat`), 이벤트 배너(루프 + 한 장씩 + 자동 넘김 + 점) |
| 영웅 | 그리드 순차 등장, 정렬 바꾸면 다시 등장, 카드 초상이 상세 화면 자리로 이어지는 **공유 요소**, 스크롤하면 접히는 제목 영역 |
| 가방 | 탭 + 한 장씩 넘기는 페이지(안에 그리드), 슬롯 아이콘이 정보 팝업으로 이어지는 공유 요소 |
| 소환 | 회전하는 마법진, 결과: 섬광 → 카드 낙하 → 한 장씩 뒤집기(4★ 빛, 5★ 흔들림·빛줄기) |
| 모험 | 챕터 캐러셀, 스테이지 순차 등장, 승리(별 3개·보상·경험치) / 패배(10번째 보스 스테이지) |
| 퀘스트 | 고정되는 섹션 헤더, 받기 → 도장 → 재화 카운트업 → 그 줄이 접혀 사라짐 |

- 장면: `Scenes/RPG.unity` (1920×1080 기준)
